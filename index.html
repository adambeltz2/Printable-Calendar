Type dates and text directly into the rows below, like a spreadsheet — or copy cells from Excel/Google Sheets and paste into the first Date box to fill in several rows at once. Dates can be 6/12/2026 or 6/12 (leave off the year for things that repeat yearly, like birthdays).

DateTextYearly

Save your spreadsheet as a CSV file with three columns — date, text, and whether it repeats yearly. Example:

date,text,yearly 6/12/1984,Mom's birthday,yes 2026-12-25,Christmas with the Smiths,no 3/17,St. Patrick's Day reminder,yes
Advanced: full backup file

Saves every event to a single file you can keep as a backup, or use to move your events to another computer. Choose "Import" above and pick this file to restore it.
